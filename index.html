Synthèse

Comment ça marche. Le texte de chaque annonce et la requête sont transformés en vecteurs TF-IDF, puis comparés par similarité cosinus. Les critères détectés (budget, carburant, boîte, ville) ajustent le classement.

En mode Local, le LLM est remplacé par des règles pour tourner hors-ligne. En mode Azure OpenAI · simulation, la page rejoue les étapes du pipeline Azure : analyse de la requête en sortie structurée, filtre OData, recherche hybride, génération avec citations, puis garde-fous anti-hallucination. La trace s'affiche sous les résultats.
